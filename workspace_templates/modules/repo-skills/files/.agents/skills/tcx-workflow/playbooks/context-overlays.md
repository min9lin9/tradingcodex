# Context Overlays

Read this playbook only when an Investment Brain, Strategy, or Decision Memory
source applies to the current workflow.

Accept at most one exact projected `$investment-brain-*` and one exact
projected `$strategy-*` selection. Do not infer or blend them.
`begin_analysis_run` seals the active `investment_brain_binding` and
`strategy_binding`. If a selected Brain is unresolved, invalid, changed, or
unavailable, stop as `waiting_for_investment_brain`; do not inspect registries
or imitate it. Service-derived provenance wins over caller-authored lineage.

Translate a selected Brain's questions and falsifiers into compact role-owned
assignments. Do not let the Brain name the team, order tasks, choose tools or
models, access Memory, or gain persistence, policy, approval, or execution
authority.

Investor Context constrains suitability. Strategy supplies applicable decision
rules. Brain shapes inquiry and interpretation. Authenticated current-run
evidence controls whether their factual conditions hold. When Brain and
Strategy conflict, apply the Strategy's decision rule; when either conflicts
with evidence, let evidence control factual claims and preserve the conflict.

Preserve an independent current-run view before Decision Memory influences a
new judgment. Treat Memory as evidence, never authority, and disclose any
material post-Memory decision change.
